# Field

Campo de texto relleno de 48 px con la etiqueta encima.

Etiqueta en estilo `label` color `ink-soft`; lo opcional se dice en la etiqueta («Nota (opcional)»), no en una ayuda aparte. Fondo `surface`, radio `radius-sm`, valor en `body` a 16 px (evita el zoom de iOS). Foco: anillo de 2 px en `primary`. Error: texto `caption` en `danger` bajo el campo que dice qué falta. Variante multilínea para la nota, 2 líneas por defecto. Reemplaza al campo subrayado con etiqueta mono de v1.
