# Button

Botón de 52 px para la acción de una pantalla o de un pie de hoja.

- **Primario** (`primary` / `on-primary`): una sola vez por pantalla. «Guardar nota».
- **Secundario** (`surface` / `ink`): acciones de apoyo junto al primario. «Repetir».
- **Marca** (`brand-jungle` / `bg`): acción social destacada en detalle. «Compartir».

Radio `radius-md`, texto `button`, ancho completo en pies de pantalla. Con icono: 18 px a la izquierda, separación `space-2`. Deshabilitado: 50 % de opacidad, sin eventos.
