# Switch

Interruptor de 50 × 30 px para opciones de sí o no que se aplican al momento.

Usos: «Compartir con amigos» en la hoja Nueva nota (recuerda la última elección) y «Recordarme a la hora del café» en Yo. Activo: pista `primary`, perilla `on-primary` a la derecha. Inactivo: pista `surface-strong`, perilla `bg` a la izquierda. Siempre con `role="switch"`, `aria-checked` y una etiqueta visible a su izquierda.
