# ListGroup

Filas agrupadas en un bloque `surface` para menús de Yo y Ajustes.

Etiqueta de grupo en `label` `ink-soft` encima del bloque. Filas de mínimo 50 px con título en `body`, subtítulo opcional en `caption`, y a la derecha un contador o chevron en `ink-soft`. Separadores `line` entre filas, ninguno arriba ni abajo. Radio `radius-md`. Una fila puede llevar un Switch en lugar del chevron.
