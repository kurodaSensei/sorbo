# Chip

Pastilla seleccionable de 34 px para sabores, cafés recientes y filtros.

- Reposo: `surface` con texto `ink`, `body` a 14 px.
- Seleccionado: `primary` con texto `on-primary`, y `aria-pressed="true"`.
- Añadir propio: borde discontinuo `line` más fuerte, texto `ink-soft`, «+ Otro».

Texto en minúscula inicial (v1 usaba mono en mayúsculas de 25 px). Separación entre chips `space-2`; filas que se envuelven, o scroll horizontal para «Recientes».
